作品の説明
HTML / CSS / PHP / Python を使って制作したセキュリティ体験型 Web アプリです。
暗号解読とパスワード強度診断を通じて、サイバーセキュリティの基礎が身につきます。
入学わずか 2 ヶ月の 1 年生が、授業で学んだ技術のみで制作しました。
⏱ 所要時間：約 5 〜 10 分　　対象：どなたでも参加できます
